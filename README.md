# 绝密航天 · 清图理包模拟器

玩家自制浏览器练习游戏，非官方。静态 HTML、CSS、原生 ES modules，无运行时 npm 依赖。

## 运行

需要 Node.js 18+ 和 Python 3：

```sh
npm test
python3 -m http.server 8000 --bind 0.0.0.0 --directory dist
```

`dist/` 为完整静态站点，应通过 HTTP 访问。游戏使用本机 `space-city-v3` 存档；保留旧存档兼容，不自动给旧枪添加配件。

## 操作

- 左侧人物/装备、中间胸挂/口袋/背包与固定安全箱、右侧战利品；手机使用分区切换。
- 容器转圈、逐件搜索，切换及刷新保留进度，搜索期间可以拿走已揭示物品。
- 拖拽到格子或装备位；缩略图保持来源像素尺寸，不放大。R 旋转，Esc 取消，靠近滚动区域边缘可滚动。拖出窗口或失焦会清理拖拽。
- 双击或 Ctrl 点击快捷转移，Alt 点击装备；单击查看物品菜单，右键枪械直接打开可拆装配件面板。头盔、护甲、武器支持拖换，装备也可直接拖进能放下它的格子。
- 胸挂/背包需搜索完成才能连同内容物互换；拖到人物旁或面板之间的空白处松手会丢到地面，保留全部包内物品和搜索进度。空装备位可拖回地面上的包重新穿戴；不支持包内套包。
- 点击枪械 →「查看 / 拆装配件」。新局枪械默认多槽模拟改装，配件随枪保存、移动、计重和结算。空间不足不会强行拆卸，已占用槽位或不兼容的专用配件不能安装。
- 枪械在装备栏、物品格、详情和拖拽中按已装配件绘制二维组合图。拆下/安装瞄具、消音器等会更新外观。旧模拟配件可以使用参考物品图展示，但其尺寸、价值、数量和初始归属保持不变。
- 自动存档、弹药合并/拆分、安全箱类型限制、地面丢弃/拾回、整理、放松模式、五分钟挑战和撤离结算均保留。

## 声音与还原范围

已移除全部循环搜索、揭示和计时相关的合成提示声。尚未提供经确认的原版物资转移音频，当前保持静音。收到音源后可保存为本地文件，并在 `dist/sound-effects.json` 的 `move` 配置其路径；默认 null，不使用合成音冒充原版。

角色为原创静态立绘，不会随装备变化。物品图来自公开资料；新增图片包含相位前握把、精英轻型/416 稳固枪托、各枪械弹鼓/弹匣与 PEQ-2。二维安装位置、枪械兼容配置和部分配件仍有模拟简化，不是原版完整三维改装系统。步枪底图包含部分默认部件，无法等同游戏内部逐零件模型。固定参考价格不是实时交易行价格，未连接游戏账号或服务器。

资源来源和许可见 `dist/credits.txt` 与 `dist/LICENSE-APACHE-2.0.txt`。

## 验证

`npm test`：13 项测试，覆盖分格边界、旋转、安全箱、失败/失效转移、弹药价值归属、搜索时序、整理不丢物品、配件拆装/满包/兼容性，以及旧配件展示升级不改变尺寸和价值。

HTTP 服务启动后，可运行：

```sh
node tests/browser-smoke.cjs
node tests/interaction-regression.cjs
node tests/ground-and-gunsmith.cjs
```

浏览器测试需要环境中可用的 Playwright 和 Chromium；没有新增到应用的 npm 依赖。实际验证包括搜索切换/刷新、头盔拖换、配件拆装/刷新、撤离、手机布局，以及不放大/不选中文字/取消拖拽/装备拖进格子/搜索计时静音。测试截图 `preview-*.png` 已加入 Git 忽略。

## 发布 GitHub Pages

发布源为 `gh-pages` 分支根目录。Settings → Pages → Deploy from a branch → gh-pages → /(root)。

提交修改后运行：

```sh
bash scripts/publish-pages.sh
```

脚本运行引擎测试后，将 `dist/` 的 Git tree 推到 `gh-pages`。不依赖 git subtree，也适用于单分支浅克隆。应用必须在推送、GitHub Pages 构建完成和线上请求检查成功后，才能称为更新上线。

地面/配件回归另验证：背包带物资丢弃、刷新、空位重新穿戴、与另一个已穿戴背包互换后重复丢弃，以及右键枪械直接拆装并刷新保留。
