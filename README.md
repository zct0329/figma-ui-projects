# 绝密航天 · 理包模拟器

玩家自制的浏览器理包练习游戏。静态 HTML / CSS / 原生 ES modules，无运行时依赖。

- 原版物品图标和胸挂、背包分格，装备、口袋、安全箱独立存放。
- 当前盒子逐件计时搜索，切换和刷新保留进度，已发现物品可提前移动。
- 拖拽放置、旋转、快捷转移、装备交换、弹药合并与拆分、地面丢弃和拾回。
- 换胸挂或背包会同时交换内容物，不会自动把原包物资搬进新包。
- 放松模式、五分钟挑战、撤离结算和战绩复制。本机自动存档。
- 手机使用分区切换，电脑使用三栏布局。

`dist/` 为静态站点。通过 HTTP 服务器访问，直接打开 HTML 文件不支持 ES 模块和目录资源获取。
`node --test tests/engine.test.mjs` 验证分格边界、安全箱规则、失败转移、弹药价值归属、搜索时序及整理不丢物资。

价格为固定资料快照。第一版不包含枪械配件拆装、背包套包、3D 地图、实时交易行或在线排行榜。界面参考原版风格，不是逐像素复刻。
物品资料与资源来源见 `dist/credits.txt` 和 `dist/LICENSE-APACHE-2.0.txt`。

## 本次迭代

- 头盔、护甲和武器可从装备位或物品格拖到自身对应装备位；原装备交换回来源。背包、胸挂仍需完成搜索后连同内容交换。
- 点击枪械 →「查看 / 拆装配件」。新一局枪械默认带多槽模拟改装；可逐件拆下、重新安装。背包满时不会强行拆卸，已占用槽位与不兼容专用配件不能安装。
- 配件随枪保存，价值、重量与开局物资归属一起计算，拆装不会额外创造收益。旧 v3 存档可继续，旧枪不自动添加配件；开始新一局可体验新配置。
- 默认开启合成搜索音，首次点击后启用，右上角可关闭。音效是机械噪声合成，并非原版录音。
- 两款瞄具、一款消音器使用已有资源；握把、枪托、弹匣、镭射使用明确标识的模拟配件与示意图。未实现原版完整枪械配件兼容表、属性或模型变化，不能视为原版满改复刻。
- 移除外部字体请求，页面资源可完全本地加载。

## 运行和验证

需要 Node.js 18+ 和 Python 3，无 npm 依赖，无需 npm install。

```sh
npm test
python3 -m http.server 8000 --bind 0.0.0.0 --directory dist
```

通过 HTTP 打开服务的 8000 端口。10 项引擎测试覆盖原有行为及无效来源转移、配件空间不足、兼容性、拆装价值与初始归属。

本次使用系统 Chromium 和 Playwright 实测：转圈搜索、切换与刷新保留进度、头盔拖拽互换、六槽配件拆装并保存、撤离结算、390px 手机随身物资分区；未出现浏览器运行错误。合成音的播放管线可运行，但听感未与原版音源对比。

## 参考图布局迭代

根据用户提供的装备界面截图，布局调整为左侧人物与装备、中间纵向容器、右侧红色标题战利品；安全箱固定在中栏底部。新增原创战术角色立绘 `dist/assets/operator.png`，它是静态插画，不会随装备变化，也不是原版角色模型。胸挂与背包保留真实独立分格，因此高度取决于当前装备。

## GitHub Pages 发布

发布文件位于 `gh-pages` 分支根目录（由 `dist/` 导出）。仓库 Settings → Pages → Build and deployment，选择 **Deploy from a branch**，分支 **gh-pages**、目录 **/(root)**，保存。页面首次构建完成后，GitHub 会在该设置页给出真实站点链接。后续发布：

```sh
bash scripts/publish-pages.sh
```

只有线上 HTTP 和浏览器检查成功，才算完成在线试玩验证。
